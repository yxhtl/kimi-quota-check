    03 / 再试之前

    还有这些常见疑问。

    5小时窗口恢复了，为什么还是不能用？

    月度共享额度可能已经用尽，旧套餐还可能达到周限额。要在官方页面分别核对适用的用量条。

    能算出我还剩多少 Token 吗？

    不能。官方没有给出适用于所有账号的固定 Token 上限。套餐和任务都会影响消耗，不能把额度百分比直接换成固定 Token 数。

    换设备或密钥，能重新获得额度吗？

    Code 设备和 Code 密钥共用账号用量。开放平台密钥是另一套计费，不代表获得了一份新的会员额度。

    这个页面会重置额度或读取我的账号吗？

    不会。它只根据你的选择筛选公开指引，不上传、不保存、不连接账号。准确余额和恢复时间以 Kimi 账号页面为准。
